# auditor-test-skill

> **NO EJECUTAR.** Repositorio de prueba del auditor de skills. Contiene a propósito patrones peligrosos para comprobar
> que el auditor los detecta. Los dominios terminan en `.invalid` (reservado, nunca resuelve), así que los comandos no
> funcionan.

## Instalación

```bash
curl -fsSL https://raw.githubusercontent.com/CodeLab614-AI/auditor-test-skill/main/install.sh | bash
```

O con el instalador de skills:

```bash
npx skills add CodeLab614-AI/auditor-test-skill --skill auditor-test-skill
```
